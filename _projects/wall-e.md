Flutter app pairing on-device TensorFlow Lite inference with Gemini suggestions for eco-friendly recycling. Camera capture → local classification → actionable disposal guidance.

**System Architecture:**
- On-device TFLite model for waste classification (privacy-first, no cloud upload)
- Camera integration with real-time inference
- Gemini AI integration for eco-friendly disposal suggestions
- Offline capability with cached recycling guidelines

**Features:**
- Multi-class waste detection (recyclable, organic, hazardous, etc.)
- Real-time classification confidence scores
- Location-based recycling center recommendations
- Educational content on proper waste sorting

**What you see:** system architecture diagram showing camera-to-classification-to-recommendation flow, mobile UI screenshots, and classification performance metrics.

**Learned:** On-device ML with TFLite, Flutter camera integration, Gemini AI API usage, and edge computing optimization.
